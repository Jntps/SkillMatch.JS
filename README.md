# SkillMatch JS 🚀

Sistema de simulação e análise de compatibilidade entre perfis profissionais e vagas de emprego, desenvolvido em JavaScript moderno para o mini-projeto do módulo de Front-End React.

## 📋 Sobre o Projeto
O **SkillMatch JS** processa de forma automatizada o perfil de um candidato, realiza uma busca assíncrona de vagas em um servidor simulado, calcula o percentual de compatibilidade com base em requisitos técnicos, identifica a melhor oportunidade de trabalho e gera uma trilha de estudos personalizada focada nas habilidades faltantes.

## 🛠️ Tecnologias e Requisitos Aplicados
- **POO (Programação Orientada a Objetos):** Criação de classes, uso de herança (`extends`, `super`) e manipulação de escopo com o operador `this`.
- **Métodos de Array Avançados:** Utilização de `.map()`, `.filter()`, `.reduce()` e `.flatMap()` para processamento de dados.
- **Assincronicidade:** Implementação de `Promise`, `setTimeout` e blocos `async/await` com tratamento de erros `try/catch`.
- **Conceitos de Funções:** Uso de *Callbacks* para modularizar o retorno de dados e *Closures* para encapsular o gerenciamento do plano de estudos.
- **Controle de Versão:** Repositório público no GitHub estruturado com estratégias de branches e histórico detalhado de commits.
